## 기존 프로세스

### ① As-Is: 기존 업무 프로세스 분석

일반적인 신약 개발에서는 후보물질을 발굴하고, 다양한 실험을 통해 효능과 안전성을 검증

후보물질 발굴 → 선도 화합물 탐색 및 최적화 → 비임상시험 → 임상시험 → 시판

**pain point**

- 후보물질 평가에 상당한 시간과 비용 발생

### ② 문제 정의: 개선 대상 파악

신약 후보물질의 안전성 검증에 많은 실험과 비용 필요. 실험 투입 전 독성 가능성이 높은 물질의 선별을 통한 불필요한 실험 감소 가능.

문제 정의 : 단순한 독성 예측을 넘어 **독성 예측의 필요성 설명**

### ③ To-Be: AI를 통한 개선 방안

**기존 프로세스**

후보물질 선정 → 실험을 통한 독성 평가 → 결과 확인 → 후속 개발 여부 결정

**AI 적용 프로세스**

후보물질 선정 → AI 기반 독성 예측 → 실험 우선순위 선정 → 독성 평가 실험 → 후속 개발 여부 결정

### ④ 데이터 분석(EDA): AI를 통한 해결 가능성 확인

다음 항목 확인 필요.

- 독성 여부와 관련된 분자 특성의 존재 여부
- 독성 물질과 비독성 물질의 분포 차이
- 학습 데이터의 충분성
- 클래스 불균형 존재 여부
- 데이터의 중복 및 오류 존재 여부

### ⑤ 모델 개발: 실제 독성 예측 가능성 검증

Random Forest, LightGBM 등의 모델 학습 및 성능 평가.

기술적 성능과 업무적 성과의 구분 필요.

| 구분        | 평가 항목                                      |
| ----------- | ---------------------------------------------- |
| 기술적 KPI  | F1 Score, Recall, Precision                    |
| 업무적 KPI  | 실험 건수 감소, 비용 절감, 평가 소요 시간 단축 |
| 안전성 지표 | 독성 물질을 안전하다고 잘못 판단하는 비율      |

# 2. 오늘 추천하는 전체 진행 순서

① 데이터 확인 → ② EDA → ③ 데이터 전처리 → ④ Baseline 모델 → ⑤ 성능 평가 → ⑥ 성능 개선 → ⑦ 최종 예측 및 제출

| 단계 | 작업                       | 예상 시간 | 목표             |
| ---- | -------------------------- | --------- | ---------------- |
| 1    | 데이터 구조 및 결측치 확인 | 20분      | 데이터 이해      |
| 2    | EDA 및 클래스 분포 확인    | 40분      | 문제 특성 파악   |
| 3    | 데이터 전처리              | 30분      | 학습 데이터 구성 |
| 4    | Baseline 모델 개발         | 50분      | 초기 성능 확보   |
| 5    | 모델 성능 분석             | 40분      | 개선 방향 결정   |
| 6    | 모델 성능 개선             | 90분      | 최적 모델 선정   |
| 7    | 최종 예측 및 제출          | 30분      | 결과물 생성      |
| 8    | 결과 정리                  | 30분      | 프로젝트 마무리  |

## Step 1. 데이터 구조 확인

데이터 확인

1. 데이터 크기 및 컬럼 구성
2. 결측치 존재 여부
3. 중복 데이터 존재 여부
4. Label 0과 1의 분포
5. 각 Feature의 데이터 타입

| Feature  | 개수  | 설명                      |
| -------- | ----- | ------------------------- |
| SMILES   | 1     | 분자 구조를 문자열로 표현 |
| ECFP     | 1,024 | 분자 구조 특성            |
| FCFP     | 1,024 | 분자의 기능적 특성        |
| PTFP     | 1,024 | 분자 패턴 특성            |
| MolWt    | 1     | 분자량                    |
| clogp    | 1     | 지용성                    |
| sa_score | 1     | 합성 난이도               |
| qed      | 1     | 약물 유사도               |
| label    | 1     | 독성 여부                 |

학습에 활용 가능한 **수치형 Feature 총 3,076개**

## Step 2. EDA (40분)

모델 학습 전 데이터의 특성 파악

### 첫 번째: Label 분포 분석

독성 물질과 비독성 물질의 비율을 확인

-> 균형 , 불균형인지 파악

### 두 번째: 분자 특성과 독성의 관계 분석

Boxplot이나 Histogram을 활용, clogp의 분포 차이가 존재하는지 확인

모델 활용을 통한 신약 개발 과정의 의사결정 개선 가능성 검토

# 3. 메모

**① 탐색적 데이터 분석 (EDA)**

목표: 데이터에서 발생하는 현상 이해

예: 특정 공정에서 불량이 발생하는 원인 분석. AI 모델 개발이 반드시 필요하지는 않음.

**② 예측 모델 개발**

목표: 데이터로 미래의 결과나 알려지지 않은 값 예측

이번 신약 독성 예측 프로젝트에 해당.

데이터의 특성, 모델 성능, 일반화 가능성을 중심으로 접근 필요.

- 모델 개발자: 예측 성능 향상 방안
- 데이터 분석가: 데이터에서의 발견 및 의사결정 지원 방안
- AX 기획자: AI를 통한 기존 업무 문제 개선 및 효과 검증 방안
